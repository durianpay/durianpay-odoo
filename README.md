# Durianpay × Odoo

Odoo 19 payment provider module for [Durianpay](https://durianpay.id), Indonesia's
payment gateway. Adds Durianpay as a checkout option via the hosted payment link
(redirect) flow, with support for both Legacy and SNAP webhook verification.

- Module: [`payment_durianpay/`](./payment_durianpay)
- How it works, webhook types, configuration reference: [`payment_durianpay/README.md`](./payment_durianpay/README.md)
- Install & usage guide (setup, manual or Docker): [`payment_durianpay/INSTALL.md`](./payment_durianpay/INSTALL.md)
